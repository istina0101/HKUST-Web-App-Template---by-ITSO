HKUST Web design system

A general system for HKUST staff-facing web apps, in the style of the ITSO IAM self-service portal. These pages are the human-readable spec; the machine-readable one is styles.css, components/ and readme.md.

What it is

The IAM portal prototype set a clear, quiet admin style: a navy band with the HKUST lockup, a white sidebar, pale-grey pages, white bordered cards, ITSO-blue actions, gold eyebrows and Lucide icons. This system records that style as tokens, components and rules so every HKUST web app can share it.
