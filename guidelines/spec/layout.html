Page anatomy

Every page: PageHead → optional stat-tile row (3 tiles) → filter row (chips left, primary action right) → one or more Cards. Detail pages add a Breadcrumb above and Tabs inside the header card. Wizards live in a single 760px-wide card with a segment Progress strip. Modals are 480px (560px for carts and wizards).
