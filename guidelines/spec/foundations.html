Type

Muli (HKUST's official content typeface, self-hosted from the files ITSO supplied; Mulish from Google Fonts is the network fallback) for all Latin text. Weights 400 body · 600 nav, labels, chips · 700 headings, buttons, badges, stats and hero titles — the set has no 800 face, so nothing is set heavier than 700. Chinese text uses the brand 黑體: 蘋果儷黑體 on macOS, 微軟正黑體 on Windows, Noto Sans TC as fallback (--font-tc). Headings line-height 1.2, body 1.5.
