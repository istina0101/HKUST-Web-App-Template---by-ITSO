Getting started

Install the tokens and fonts, then compose screens from the components.

Download skill.zip

HKUST Web is a design system for HKUST staff-facing web applications, derived from the ITSO IAM self-service portal. Navy carries the brand, ITSO blue carries action, Muli sets the type, Lucide draws the icons. One CSS entry file ships every token and font; 65 React components implement the patterns.

Plain HTML + CSS

Copy the system folderTake styles.css, tokens/ and assets/ into your project. styles.css is only @import lines; everything else hangs off it.
Link the entry stylesheet
<link rel="stylesheet" href="/styles.css">
Use the tokensEvery colour, size, radius and shadow is a CSS custom property on :root. Never hard-code the hex.
.card { background: var(--surface-card); border: 1px solid var(--border); border-radius: var(--r-lg); padding: var(--card-pad); }
.btn-primary { background: var(--action-primary); color: #fff; font: var(--weight-bold) var(--text-sm) var(--font-body); padding: var(--btn-pad); border-radius: var(--r-md); }

React project

Copy components/Each component is one .jsx with a sibling .d.ts (props) and .prompt.md (usage). The only dependency is React; styling is inline and token-driven, so the entry stylesheet must be loaded.
Import and compose
import { TopBand, Sidebar, NavItem, PageHead } from './components/navigation';
import { Card, Button, Badge } from './components/core';

<TopBand logoSrc="/assets/logo/hkust-fullname-white.png" unit="Information Technology" unitSub="Services Office (ITSO)" user={{ initials: 'KM', name: 'WONG Ka Ming', role: 'ITSO' }} />
<Sidebar collapsible title="Research Computing Portal">
  <NavItem icon="layout-grid" active>Dashboard</NavItem>
</Sidebar>
Follow the shellBand 60px · sidebar 248px (64px collapsed, drawer ≤880px) · sticky page head · content inset 26px 32px 64px, max 1320px. See Layout & motion.

Claude Code skill

The whole system is packaged as an Agent Skill: SKILL.md, the readme, tokens, fonts, logos, all component sources and the four templates (82 files).

Download and unziphkust-web-design-skill.zip → unzip into ~/.claude/skills/ (or a project's .claude/skills/). The archive already contains the hkust-web-design/ folder.
Invoke
/hkust-web-design  build a staff leave-approval dashboard
Claude reads the readme and component sources and designs on-brand HTML or production code.

Fonts

Muli is self-hosted in assets/fonts/ (10 faces, 200–700 upright and italic) and declared in tokens/fonts.css. The set has no 800 face; nothing in the system is set heavier than 700 and font-synthesis: none stops browsers faking one. Mulish from Google Fonts is the network fallback.

Chinese text uses the brand 黑體: 蘋果儷黑體 (LiHei Pro) on macOS, 微軟正黑體 (Microsoft JhengHei) on Windows, PingFang TC, then Noto Sans TC from Google Fonts. These are system fonts and are named, not shipped. --font-tc is the Chinese-only stack.

The Muli files are licensed to HKUST. Keep the repository private or remove assets/fonts/ before publishing publicly (the Mulish fallback takes over).
